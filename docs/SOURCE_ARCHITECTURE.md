**## 一、平台定位**



**\*\*AI 创新平台\*\***（InnovationCore AI Platform）是企业级 MaaS（Model as a Service）平台，面向内部研发团队，提&#x4F9B;**\*\*模型服务化、数据与测评、Agent 应用\*\***&#x4E09;大核心能力的一站式服务平台。



平台&#x4EE5;**\*\*大模型评测为核心抓手\*\***，覆盖从模型接入、能力评测、报告生成到应用落地的全生命周期，同时提供 AI School 实训环境、数据中心治理工具箱和丰富的 Agent 应用生态。

**## 三、四大核心业务模块**



**### 1. MaaS 服务 — 模型即服务**



**| 子功能 | 说明 |**

**|--------|------|**

**|** **\*\*模型广场\*\*** **|** 展示所有已注册模型，支持模型详情查看、多维度能力雷达图对比、多模型并列柱状图对比 **|**

**|** **\*\*模型榜单 (Leaderboard)\*\*** **|** Ruler1（通用能力榜）/ Ruler2（领域能力榜）/ 多模态榜 / LM Arena 竞技场榜，支持多期趋势对比 **|**

**|** **\*\*模型选型\*\*** **|** 根据场景推荐合适模型（语言类/专业类），引导用户选择最优模型 **|**

**|** **\*\*运营看板\*\*** **|** 用户操作统计（活跃度、趋势、部门分布、Top用户）、数据集统计、评测统计、儿童研究统计 **|**

**|** **\*\*模型部署\*\*** **|** 模型部署申请与审批流程管理 **|**



**\*\*支持的评测维度\*\***：

**-&#x20;**&#x901A;用能力：MMLU、C-Eval、GSM8K、HumanEval、LiveCodeBench、AIME 等 30+ 基准

**-&#x20;**&#x9886;域能力：通信领域（AISF 意图分类/功能调用/记忆/澄清对话/感知规划等）

**-&#x20;**&#x591A;模态能力：VLM 评测、ASR/MT/TTS 同声传译评测

**-&#x20;**&#x7ADE;技场：类 Chatbot Arena 的匿名对战排名（LM Arena）



**### 2. 数据与评测 — Data & Evaluation**



**| 子功能 | 说明 |**

**|--------|------|**

**|** **\*\*数据集仓库\*\*** **|** 测试集/训练集的管理、注册、版本管理、文件浏览与下载、目录树导航 **|**

**|** **\*\*数据标注\*\*** **|** 基于 AIS&#x46;**-**&#x43;ompanion 的在线数据集标注工具 **|**

**|** **\*\*评测任务管理\*\*** **|** 一键提交评测任务（Ruler1/Ruler2/VLM/Dev/AISF Release），支持暂停/恢复/取消 **|**

**|** **\*\*评测进度追踪\*\*** **|** 实时任务进度查看、日志流式输出、子任务完成状态 **|**

**|** **\*\*在线评估\*\*** **|** 可视化在线评估流程：选择数据集 → 选择模型 → 启动评估 → 查看结果 **|**

**|** **\*\*多模型对比评估\*\*** **|** 同声传译（ASR/MT/TTS）的多模型并行评估与结果对比 **|**

**|** **\*\*评测报告系统\*\*** **|** 自动生成评测报告、报告发布与管理、报告在线预览 **|**

**|** **\*\*数据治理\*\*** **|** 数据集下载/查看统计、VLA 数据总览（场景/应用维度） **|**



**### 3. Agent 应用 — AI Agent Ecosystem**



**| 子功能 | 说明 |**

**|** **\*\*Deep Research\*\*** **|** 深度研究助手，自动搜索、分析、撰写研究报告 **|**

**|** **\*\*论文中英翻译\*\*** **|** 学术论文全文翻译服务 **|**

**|** **\*\*模型高速下载\*\*** **|** HuggingFace / ModelScope 模型与数据集高速下载工具 **|**

**|** **\*\*第三方 Agent 集成\*\*** **|** 集成 Dify、Coze、Owl 等第三方低代码 Agent 平台 **|**



**### 4. AI School — AI 实训平台**



**| 子功能 | 说明 |**

**|--------|------|**

**|** **\*\*模型训练\*\*** **|** 在线 GPU/NPU 资源调度，支持 Python 脚本提交训练任务，实时日志查看 **|**

**## 七、适用场景**



**1. \*\*模型选型决策\*\***：通过多维榜单和对比工具，选择最适合业务场景的基础模型

**2. \*\*模型能力验收\*\***：对第三方模型或自研模型进行全面的通用/领域能力评测

**3. \*\*研发效能提升\*\***：论文助手每日推送最新 AI 研究动态，Prompt 优化器辅助提示工程

**4. \*\*Agent 应用开发\*\***：集成多种 Agent 框架，快速构建和验证 AI 应用

**5. \*\*AI 人才培养\*\***：AI School 提供零门槛的模型训练推理实训环境

**6. \*\*数据资产管理\*\***：数据集仓库 + 数据标注 + VLA 数据总览，一站式数据治理
